# Support

## Questions and setup help

Read the [README](README.md), [Google OAuth setup guide](docs/google-oauth-setup.md), and [troubleshooting section](docs/google-oauth-setup.md#troubleshooting) first.

If the problem remains, open a [GitHub Discussion](https://github.com/itsixteen/multi-gmail/discussions) with:

- macOS version
- Node.js version
- Codex surface and version
- the command that failed
- the exact error with all email addresses, client IDs, tokens, message content, and local paths removed

## Bugs

Use the bug report form in [GitHub Issues](https://github.com/itsixteen/multi-gmail/issues/new/choose). Include the smallest reproducible case you can provide without sharing private email data.

## Security issues

Do not open a public issue. Follow [SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.

## What maintainers cannot do

Maintainers cannot access your Google Cloud project, Gmail accounts, Keychain, local Codex configuration, or OAuth credentials. Never send those secrets to a maintainer.
