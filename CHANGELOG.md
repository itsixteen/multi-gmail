## [0.1.0] - 2026-08-07

### Added

- Local stdio MCP server with 11 Gmail tools.
- Multi-account reads through `account="all"`.
- Explicit single-account boundaries for every write.
- Gmail search, message and thread reading, label inspection, triage, Trash and restore, drafts, and sending.
- macOS Keychain storage for OAuth refresh tokens.
- OAuth PKCE, random state, and loopback callback handling.
- Per-account error reporting for cross-account operations.
- Codex plugin manifest, skill, and Git marketplace packaging.
