# Code of Conduct

## Our commitment

We are committed to a welcoming, respectful, and harassment-free community for everyone, regardless of experience, identity, background, or ability.

## Expected behavior

- Be respectful and constructive.
- Critique ideas and code, not people.
- Assume good intent while accepting responsibility for impact.
- Protect user privacy and never request unnecessary credentials or mailbox data.
- Respect project security boundaries and coordinated disclosure.

## Unacceptable behavior

- Harassment, intimidation, discrimination, or personal attacks.
- Publishing another person's private information without permission.
- Sharing credentials, private email content, or exploit details that put users at immediate risk.
- Repeated disruption of project discussions or review.

## Enforcement

Maintainers may edit, remove, or reject contributions and participation that violate this code. For a confidential report, use GitHub private vulnerability reporting and state that the report concerns community conduct rather than a software vulnerability.

This code applies in project spaces and when representing the project in public spaces.
